# Get the seven Ordering products

Paste this into your coding agent when you want product setup, with or without an existing Ordering connection:

```text
Use https://github.com/Ordering-co/ordering-dev-quickstart and follow docs/products.md, safely reusing my existing checkout and preserving its changes. Download all seven public products into ~/ordering-products and configure all seven for my confirmed authorized project. Reuse my verified project identity if available, or ask for its public slug without creating another login. Ask once for an explicit franchise choice for both franchise products if needed. Preserve existing files, branches, remotes, SDK pins and unknown configuration; never copy credentials. Then ask which products I want to run locally, recommending Website Marketplace and Dashboard together. Install dependencies and start only my selected products. Verify their displayed destination and one visible reversible edit; report cloning, configuration and running separately, including partial failures.
```

The standalone clone/configure commands do not need Ordering login or access to private repositories. App login and optional Context7 remain separate. See [the products guide](../docs/products.md) for the exact commands and runbooks.
