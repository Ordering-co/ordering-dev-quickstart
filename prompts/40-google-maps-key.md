# Create my own Google Maps key

Paste this into your agent from `~/ordering-dev-quickstart`, after your Ordering connection is verified:

```text
Set up my own Google Maps key for my Ordering project. Follow docs/google-maps.md: check that gcloud is installed (help me install it if not), then run ./ordering google-maps setup. Relay any Google sign-in link to me, tell me if I need to add a payment method or choose a billing account, show me what it will change and wait for my yes before running it again with --yes. Never print the key.
```
