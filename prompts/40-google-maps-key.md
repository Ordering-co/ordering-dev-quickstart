# Create my own Google Maps key

New projects start with Ordering's Google Maps key, which only works on Ordering's own domains. Add your own so maps and address search work on your custom domains and apps.

## Already connected to Ordering

Paste this into your agent if you already connected with this quickstart:

```text
I'm already connected to Ordering with ~/ordering-dev-quickstart. Set up my own Google Maps key for that same project: follow step 8 of SETUP.md and docs/google-maps.md without signing in to Ordering again. Guide me through installing gcloud if needed, the Google sign-in and, if I have none, creating a Google billing account. Show me what it will change and wait for my yes before running it with --yes. Never print the key.
```

## Not connected yet

Use [the setup prompt](00-setup.md). After your connection is verified, the agent offers this step.
